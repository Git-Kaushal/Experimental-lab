Visual Labs

Interactive 3D experiments. Open one full screen, or use Enter AR / Enter VR inside a lab on a supported device.

Add a new lab

1) Upload the lab file (for example my-lab.html) to the same folder as this page.
2) Add a line to the LABS list near the bottom of this page's source:

{t:'Title',f:'my-lab.html',d:'One-line description',tags:['Chemistry'],s:'Live'}

Use s:'Archive' for previously executed experiments. Keep every lab as a single self-contained HTML file and serve the site over HTTPS (needed for AR).
